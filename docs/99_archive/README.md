| 路径 | 内容 | 使用方式 |

## UI 证据取舍

- 保留 `config.json`、`design.json`，作为设计系统和工具裁定的结构化记录。
- 保留桌面与任务笺批准稿、对应 prompt、六张最终界面截图及最终评审/裁定。
- 删除可再生的构建网格、scaffold、区域切图、差异热图和报告，以及未采用方案的重复效果图。
- 历史文档中的旧目录名、旧版本号和当时路径属于原始记录，不代表当前有效路径。

归档内容不得被运行代码或打包流程依赖；需要恢复已删除过程产物时，可从 T2 前置提交 `ee978c7` 的 Git 历史读取。
