# 智能任务管家 V1.2 现代新中式重设计实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在完整保留 V1.0.7 功能、数据和安全边界的前提下，把 Electron 桌面应用升级为 V1.2 的现代新中式企业级界面，并交付统一图标、响应式适配、克制动效、轻量桌面任务笺、自动化验证、发布文档与便携版构建证据。

**Architecture:** 保持现有 Electron 主进程、preload、安全附件模块和原生 JavaScript 业务模块边界不变；重构渲染层语义结构，把单一大样式表拆成令牌、基础、布局、组件和动效五个职责文件。新增受限 IPC 驱动的独立桌面任务笺，主界面保持任务数据唯一写入方；新建纯函数式图标、任务笺模型和动效适配模块，以可降级接口接入现有 `app.js`，真实窗口测试继续作为双窗口、DOM、附件事务和交互兼容性的主要回归门槛。

**Tech Stack:** Electron 31、Vanilla JavaScript、HTML5、CSS3、GSAP 3、本地 Noto Serif SC 字体资源、Node.js `node:test`、electron-builder、Impeccable 视觉检查。

**Spec:** `docs/superpowers/specs/2026-09-21-v1.2-modern-chinese-redesign-design.md`

## Global Constraints

- 正式软件版本为 `1.2.0`，界面版本显示为 `V1.2`。
- 产品继续是 Windows 本地优先的个人任务与 AI 助手，不新增账号、云同步、团队协作、遥测或后端服务。
- 保持全部现有 `localStorage` 键名、任务数据、AI 会话和 `%APPDATA%\智能任务管家\运行数据\task-attachments` 附件目录兼容。
- 不削弱 `contextIsolation: true`、`nodeIntegration: false`、preload 最小暴露、附件事务、路径校验和 HTTP/HTTPS 外链限制。
- 运行时不得从 CDN、远程字体服务或第三方图标服务加载资源。
- 视觉气质固定为细腻、低调、优雅的现代新中式；不使用高饱和渐变、霓虹发光、廉价金色、密集圆角卡片或表情符号操作图标。
- 布局必须覆盖 1366×768、1440×900、1920×1080、2560×1440、较窄窗口和 Windows 125%／150% 缩放，不得出现横向撕裂、重叠、裁切或操作不可达。
- 内容默认可见；GSAP 只增强状态变化，缺失、报错或 `prefers-reduced-motion` 时不得影响功能。
- 桌面任务笺固定不置顶、不抢焦点、不直接写入 `smart_tasks`，并在显示器或 DPI 变化后保持完整可见。
- 现有 67 项单元测试必须保持 0 失败；环境不支持符号链接时允许原有 2 项按既定条件跳过。

- [ ] **Step 3: Implement the degradable motion controller**

Create `renderer/motion.js` with the project UMD pattern and this contract:

```js
function capturePositions(nodes) {
  return new Map([...nodes].map(node => {
    const { left, top } = node.getBoundingClientRect();
    return [node.dataset.id, { left, top }];
  }));
}
function createMotionController({
  gsap,
  prefersReducedMotion = () => globalThis.matchMedia?.("(prefers-reduced-motion: reduce)").matches
} = {}) {
  const enabled = () => Boolean(gsap) && !prefersReducedMotion();
  return {
    animateTaskReflow(elements, before) {
      if (!enabled()) return;
      for (const node of elements) {
        const previous = before.get(node.dataset.id);
        if (!previous) continue;
        const current = node.getBoundingClientRect();
        gsap.fromTo(node,
          { x: previous.left - current.left, y: previous.top - current.top, opacity: .72 },
          { x: 0, y: 0, opacity: 1, duration: .22, ease: "power2.out", clearProps: "transform,opacity" });
      }
    },
    animateAssistant(panel, collapsed) {
      if (!enabled()) return;
      gsap.to(panel, { opacity: collapsed ? .82 : 1, x: 0, duration: .22, ease: "power2.out", clearProps: "transform" });
    },
    animateDialog(card) {
      if (enabled()) gsap.fromTo(card, { y: 8, opacity: 0 }, { y: 0, opacity: 1, duration: .18, ease: "power2.out", clearProps: "transform,opacity" });
    },
    animateToast(node) {
      if (enabled()) gsap.fromTo(node, { y: -6, opacity: 0 }, { y: 0, opacity: 1, duration: .16, ease: "power2.out", clearProps: "transform,opacity" });
    }
  };
}
```
