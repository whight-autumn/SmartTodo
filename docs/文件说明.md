# 文件说明 · SmartTodo

当前文档版本：V1.5.0（2026-10-16）。项目为 Electron Windows 桌面应用，采用主进程、两个隔离 preload 与主／任务笺渲染器分层。

## 根目录

| 文件 | 职责 |
| --- | --- |
| `main.js` | 主进程入口。单实例锁后、Chromium 打开配置前解析运行路径并处理迁移；设置实际 userData，再创建窗口／任务笺。管理隐藏标题栏、主题同步、托盘、通知、隐藏启动和生命周期；注册附件、任务笺及固定 IPC，迁移前刷新 DOMStorage 与严格持久化任务笺偏好。 |
| `main-paths.js` | 默认目录与附件路径、历史目录兼容，以及运行路径解析委托；自定义路径不触发未使用默认目录迁移。 |
| `runtime-data-manager.js` | 固定引导文件 `%APPDATA%\SmartTodo\bootstrap.json`；路径／普通文件安全检查、原子请求、启动前整目录复制、相对路径／大小／SHA-256 清单、时间戳备份、新路径激活、中断验证恢复与结果消费。无法验证原数据或保存恢复状态时停止启动。 |
| `app-launch-spec.js` | 自启动与迁移重启共用的纯启动参数解析：便携外层 EXE、普通包当前 EXE、开发 Electron 加应用目录；校验便携路径；登录启动追加隐藏标记，设置页迁移后可见重启。 |
| `login-startup.js` | Windows 持久可执行路径和应用参数后的 `--hidden` 启动项写入；以 openAtLogin 校验完整登记，并按可执行文件路径读取程序批准状态与实际 enabled；兼容 Electron 省略启动项参数回传；其他平台返回不可用。 |
| `app-settings-ipc.js` | 五个固定设置通道，校验当前主窗口身份和精确 payload；原生目录选择、5 分钟／一次性／发送者绑定凭证、存储刷新后排队／重启、迁移结果消费及固定安全错误。渲染器不能提交任意路径。 |
| `preload.js` | 主界面最小 `window.desktop` 桥接。固定通知、版本、窗口主题、附件、任务笺与五个设置接口；只转发经过校验的参数，不暴露 Electron 对象或任意通道。 |
| `widget-preload.js` | 任务笺最小 `window.taskWidget` 桥接，仅允许读取快照、请求完成、隐藏自身、打开主界面和接收快照。 |
| `widget-controller.js` | 创建 320×440、透明、无边框、不置顶、不进任务栏的任务笺；用 `showInactive()` 显示并持久化位置／可见性。迁移使用可抛错的严格原子偏好刷新，普通退出仍为尽力刷新。 |
| `widget-window-state.js` | 清理任务笺偏好、计算右侧默认位置、在多显示器与负坐标工作区中夹取安全边界。 |
| `widget-ipc.js` | 双窗口固定 IPC。校验发送者身份与精确 payload，转发脱敏快照和带超时的完成请求。 |
| `task-attachment-store.js` | 受管附件存储、数量／大小限制、规范路径与文件身份校验，以及单调准备／提交／回滚／启动协调事务。 |
| `task-attachment-ipc.js` | 附件固定 IPC 与 HTTP/HTTPS 外链边界。 |
| `package.json` / `package-lock.json` | V1.5.0 SmartTodo 元数据、依赖锁及启动／测试／Windows 便携构建命令；显式包含全部主进程模块。 |
| `README.md` | 用户与开发者入口文档。 |
| `PRODUCT.md` | 产品定位、能力边界、品牌承诺与验证依据。 |
| `CHANGELOG.md` | 版本更新记录。 |
| `DESIGN.md` | V1.2 设计系统与响应式规则。 |
| `release/版本迭代说明.md` | 历史公开版本及 V1.5.0 的产品演进与兼容说明。 |

## renderer/ 主界面与任务笺

| `styles/motion.css` | 状态过渡及减弱动效规则。 |
| `vendor/gsap.min.js` | 本地 GSAP 运行时；不依赖 CDN。 |

## 关键调用关系

```text
main.js ── main-paths.js ── runtime-data-manager.js（Chromium 配置打开前）
   ├── login-startup.js（OS 状态）
   ├── app-settings-ipc.js ◀── preload.js
   ├── widget-controller.js ── BrowserWindow(renderer/widget.html)
   │              │
   │              └── widget-window-state.js
   ├── widget-ipc.js ◀── preload.js / widget-preload.js
   ├── task-attachment-ipc.js ── task-attachment-store.js
   └── BrowserWindow(renderer/index.html)

renderer/app.js ── SettingsController ◀── window.desktop（固定设置能力）
                └── RecurrenceModel / TaskModel / WidgetModel / UIAppearance / MotionSystem
renderer/widget.js ── RecurrenceModel / WidgetModel / IconUtils / window.taskWidget
```

主界面是 `smart_tasks` 的唯一写入者。任务笺只显示脱敏快照，并通过固定请求让主界面完成与持久化任务；保存失败时恢复所有受影响任务字段。
