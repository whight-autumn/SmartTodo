# 文件说明 · SmartTodo

当前文档版本：V1.3.1（2026-09-22）。项目为 Electron Windows 桌面应用，采用主进程、两个隔离 preload 与主／任务笺渲染器分层。

## 根目录

| 文件 | 职责 |
| --- | --- |
| `main.js` | Electron 主进程入口。创建主窗口和桌面任务笺，管理托盘、通知、单实例、旧数据目录兼容与退出流程；注册附件和任务笺固定 IPC。 |
| `main-paths.js` | 生成 `%APPDATA%\SmartTodo\运行数据` 及附件根目录，并安全迁移两个历史运行目录。 |
| `preload.js` | 主界面最小 `window.desktop` 桥接。只暴露固定通知、版本、附件与任务笺接口；不暴露 Electron 对象或任意通道。 |
| `widget-preload.js` | 任务笺最小 `window.taskWidget` 桥接，仅允许读取快照、请求完成、隐藏自身、打开主界面和接收快照。 |
| `widget-controller.js` | 创建 320×440、透明、无边框、不置顶、不进任务栏的任务笺窗口；用 `showInactive()` 显示并持久化位置／可见性。 |
| `widget-window-state.js` | 清理任务笺偏好、计算右侧默认位置、在多显示器与负坐标工作区中夹取安全边界。 |
| `widget-ipc.js` | 双窗口固定 IPC。校验发送者身份与精确 payload，转发脱敏快照和带超时的完成请求。 |
| `task-attachment-store.js` | 受管附件存储、数量／大小限制、规范路径与文件身份校验，以及单调准备／提交／回滚／启动协调事务。 |
| `task-attachment-ipc.js` | 附件固定 IPC 与 HTTP/HTTPS 外链边界。 |
| `package.json` / `package-lock.json` | V1.3.1 SmartTodo 元数据、依赖锁、启动／测试／UI 测试／便携构建命令和显式打包清单。 |
| `README.md` | 用户与开发者入口文档。 |
| `PRODUCT.md` | 产品定位、能力边界、品牌承诺与验证依据。 |
| `CHANGELOG.md` | 版本更新记录。 |
| `DESIGN.md` | V1.2 设计系统与响应式规则。 |

## renderer/ 主界面与任务笺

| 文件 | 职责 |
| --- | --- |
| `index.html` | SmartTodo 主界面语义骨架：品牌栏、任务工作台、知行助手、备注／附件、设置与确认对话框。 |
| `app.js` | 主界面唯一业务与任务持久化入口；管理任务、周期调度、提醒指纹、筛选、备注、附件、AI、主题、亮度、动效和任务笺快照／完成回滚。 |
| `widget.html` / `widget.css` / `widget.js` | 桌面任务笺语义结构、现代中式半透明外观和受限交互；支持 100%／125%／150% 缩放与减弱动效。 |
| `widget-model.js` | 任务笺纯逻辑：最多 5 项选择顺序、父任务名称解析、重复／承接只读标签、提醒文案、亮度约束和字段白名单快照。 |
| `recurrence-model.js` | 纯日历周期逻辑：04:00 边界、周期键、锚点提醒投影、月末／闰日处理、标签与提醒指纹。 |
| `task-model.js` | 任务规范化、排序、父子索引、周期刷新／承接、完成／撤销、15 天清理与关注筛选。 |
| `draft-store.js` | 任务表单草稿保存与恢复。 |
| `ai-provider.js` | DeepSeek、OpenAI 与自定义 OpenAI-compatible 配置及 SSE 增量解析。 |
| `ui-appearance.js` | 亮度读写、任务时间格式和 V1.3 显示版本格式。 |
| `note-utils.js` | 备注纯文本转义与安全 HTTP/HTTPS 链接生成。 |
| `icon-utils.js` / `icons.svg` | 固定图标词汇、可访问 SVG 标记与统一线性图标符号。 |
| `motion.js` | GSAP 状态动效控制器及 `prefers-reduced-motion` 回退。 |
| `style.css` | 按顺序聚合五层样式。 |
| `styles/tokens.css` | 深浅主题颜色、字体、圆角、阴影、边线和动效令牌。 |
| `styles/base.css` | 重置、排版、焦点、滚动条和辅助类。 |
| `styles/layout.css` | 主工作台、窄窗口与助手折叠布局。 |
| `styles/components.css` | 任务、筛选、编辑器、附件、对话框、按钮和状态组件。 |
| `styles/motion.css` | 状态过渡及减弱动效规则。 |
| `vendor/gsap.min.js` | 本地 GSAP 运行时；不依赖 CDN。 |

- `ui-smoke.cjs`：主界面任务、周期重载幂等、提醒指纹、筛选、主题、IME、AI 失败恢复与附件事务。
- `ui-layout.cjs`：重复／承接标签、1366×768 至 2560×1440、窄窗、125%／150% 缩放与零横向溢出。
- `ui-widget.cjs`：真实双窗口重复标签、焦点、五任务顺序、主题／亮度同步、成功完成、保存失败回滚与三档缩放。

## 关键调用关系

```text
main.js ── widget-controller.js ── BrowserWindow(renderer/widget.html)
   │              │
   │              └── widget-window-state.js
   ├── widget-ipc.js ◀── preload.js / widget-preload.js
   ├── task-attachment-ipc.js ── task-attachment-store.js
   └── BrowserWindow(renderer/index.html)

renderer/app.js ── RecurrenceModel / TaskModel / WidgetModel / UIAppearance / MotionSystem
renderer/widget.js ── RecurrenceModel / WidgetModel / IconUtils / window.taskWidget
```

主界面是 `smart_tasks` 的唯一写入者。任务笺只显示脱敏快照，并通过固定请求让主界面完成与持久化任务；保存失败时恢复所有受影响任务字段。
