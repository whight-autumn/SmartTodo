# 文件说明 · SmartTodo

最后更新: 2026-10-16 | 对应版本: v1.5.0

项目为 Electron Windows 桌面应用，采用根入口、主进程支持层、两个隔离 preload 与主／任务笺渲染器分层。

## 根目录

| 文件 | 职责 |
| --- | --- |
| `main.js` | 主进程入口。单实例锁后、Chromium 打开配置前解析运行路径并处理迁移；设置实际 userData，再创建窗口／任务笺。管理隐藏标题栏、主题同步、托盘、通知、隐藏启动和生命周期；注册附件、任务笺及固定 IPC，迁移前刷新 DOMStorage 与严格持久化任务笺偏好。 |
| `package.json` / `package-lock.json` | V1.5.0 SmartTodo 元数据、依赖锁及启动／测试／Windows 便携构建命令；显式包含 `main.js`、`src/**/*`、renderer 与 assets。 |
| `AGENTS.md` / `ENGINEERING_CHARTER.md` | Agent 入口摘要与 EC v1.4.0 工程规则正本。 |
| `README.md` | 用户与开发者入口文档。 |

## src/main/ 主进程支持层

| 文件 | 职责 |
| --- | --- |
| `paths/main-paths.js` | 默认目录、附件路径和历史目录兼容；延迟委托运行目录迁移，避免与 runtime 模块的初始化循环。 |
| `runtime/runtime-data-manager.js` | 固定引导文件、路径安全检查、原子请求、整目录复制与 SHA-256 清单、时间戳备份、激活、中断恢复和结果消费。 |
| `startup/app-launch-spec.js` | 解析便携、普通包和开发模式的持久启动命令；迁移重启保持可见，登录启动追加 `--hidden`。 |
| `startup/login-startup.js` | Windows 启动项写入与 OS 权威状态读取；其他平台返回不可用。 |
| `settings/app-settings-ipc.js` | 五个固定设置通道、主窗口发送者校验、原生目录选择和一次性迁移凭证。 |
| `attachments/task-attachment-store.js` | 受管附件数量／大小／路径校验，以及准备、提交、回滚和启动协调事务。 |
| `attachments/task-attachment-ipc.js` | 附件固定 IPC、受管文件打开与 HTTP/HTTPS 外链边界。 |
| `widget/widget-controller.js` | 创建并控制 320×440 非抢焦点任务笺，持久化位置与可见性。 |
| `widget/widget-window-state.js` | 清理偏好、计算默认位置并把窗口夹取到多显示器安全边界。 |
| `widget/widget-ipc.js` | 校验双窗口发送者和精确 payload，转发脱敏快照及带超时的完成请求。 |

## src/preload/ 隔离桥接

| 文件 | 职责 |
| --- | --- |
| `src/preload/main-preload.js` | 暴露最小 `window.desktop`：通知、版本、主题、附件、任务笺和五个设置能力；不暴露 Electron 对象或任意通道。 |
| `src/preload/widget-preload.js` | 暴露最小 `window.taskWidget`：读取快照、请求完成、隐藏自身、打开主界面和接收快照。 |

## 关键调用关系

```text
main.js ── src/main/paths/main-paths.js ── src/main/runtime/runtime-data-manager.js（Chromium 配置打开前）
   ├── src/main/startup/login-startup.js（OS 状态）
   ├── src/main/settings/app-settings-ipc.js ◀── src/preload/main-preload.js
   ├── src/main/widget/widget-controller.js ── BrowserWindow(renderer/widget.html)
   │              │
   │              └── src/main/widget/widget-window-state.js
   ├── src/main/widget/widget-ipc.js ◀── src/preload/main-preload.js / src/preload/widget-preload.js
   ├── src/main/attachments/task-attachment-ipc.js ── src/main/attachments/task-attachment-store.js
   └── BrowserWindow(renderer/index.html)

renderer/app.js ── SettingsController ◀── window.desktop（固定设置能力）
                └── RecurrenceModel / TaskModel / WidgetModel / UIAppearance / MotionSystem
renderer/widget.js ── RecurrenceModel / WidgetModel / IconUtils / window.taskWidget
```

主界面是 `smart_tasks` 的唯一写入者。任务笺只显示脱敏快照，并通过固定请求让主界面完成与持久化任务；保存失败时恢复所有受影响任务字段。
