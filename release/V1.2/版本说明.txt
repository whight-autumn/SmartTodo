SmartTodo V1.2
版本：1.2.0
日期：2026-09-21
版本归属：萤火

本次更新
1. 全面更新为简洁、细腻、低调优雅的现代中式“文房案台”界面。
2. 统一重绘竹叶流萤品牌图标、应用图标、托盘图标和界面线性图标。
3. 新增桌面任务笺：在桌面右侧显示最多 5 项任务，可完成任务、打开主界面或收起。
4. 桌面任务笺不置顶、不抢占焦点，支持位置记忆和显示器变化后的安全回收。
5. 优化 1366×768 至 2560×1440、窄窗口及 Windows 125%／150% 缩放适配。
6. 优化状态动效、减少动态效果模式、长标题／长链接／长文件名和中文输入法行为。

任务笺任务顺序
已逾期 → 24 小时内到期 → 置顶 → 高优先级 → 其余任务；最多显示 5 项未完成任务。

数据兼容
V1.2 继续使用原有运行数据、localStorage 键名与附件目录，可直接覆盖升级，无需迁移。
建议升级前从系统托盘完全退出旧版本，并备份：
%APPDATA%\智能任务管家\运行数据

隐私说明
任务、附件、会话、设置和 API Key 均保存在本机。AI 功能只在用户自行配置服务后联网，任务管理不依赖网络。
