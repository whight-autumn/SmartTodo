SmartTodo V1.5.0 版本说明
发布日期：2026-10-16（Windows x64 便携版已发布）

一、主要修复
1. 移除主窗口顶部与浅色主题反差明显的 Windows 默认标题栏。
2. 保留 Windows 原生最小化、最大化和关闭按钮，避免自制窗口控件造成行为差异。
3. 宽屏以 114px 一体化顶栏承载 36px 透明拖动层，图标、品牌说明与工具按整体高度居中；720px 及以下保留独立系统按钮安全区。
4. 顶部工具的视觉顺序与键盘焦点顺序保持一致，减少无效留白并改善视觉比例。
5. 深浅主题切换时同步窗口按钮符号色；主题 IPC 仅接受主窗口发送的 light／dark 精确参数。

二、兼容性
- 不改变任务、提醒、会话、AI 配置、主题、运行目录或附件数据结构。
- 开机自启动、托盘、任务笺、提醒点击唤起和运行数据迁移行为保持不变。
- 继续使用 contextIsolation: true 与 nodeIntegration: false。

三、验证状态
- 已增加生产窗口配置、发送者校验、preload 参数校验和拖动区结构回归测试。
- npm test 共 312 项：310 项通过、0 项失败、2 项因当前 Windows 环境无法创建测试用文件符号链接而跳过。
- Electron 主界面行为、响应式矩阵及真实双窗口任务笺 UI 流水线通过。
- Windows x64 便携包构建成功；版本资源为 1.5.0，包内关键主进程、设置、迁移、preload 与标题栏文件核对通过。
- 当前产物未签名，Windows 首次运行可能显示 SmartScreen 提示。
