智能任务管家 V1.0.7
日期：2026-09-15
所属：萤火
状态：正式发布

本次更新
1. 修复备注编辑器中正常已保存附件错误显示“文件已不存在”的样式优先级问题。
2. 正常附件不再显示缺失状态；仅当主进程确认附件缺失、不安全或无法解析时显示该提示。
3. 增加真实窗口回归测试，验证正常附件状态默认隐藏，避免后续样式调整再次引入问题。
4. 已完成任务的附件不会在勾选完成时立即删除，以保留 15 天内撤销能力。
5. 已完成超过 15 天的任务自动清理时，其主任务、子任务及对应附件目录会同步清理。
6. 手动删除任务时同步删除对应附件目录；程序启动时还会幂等清理没有任务引用的孤立附件。

数据与兼容性
本次修改不改变任务、备注或附件数据结构，兼容 V1.0.6 现有运行数据。附件仍保存在：
%APPDATA%\智能任务管家\运行数据\task-attachments\<任务ID>\

说明
本版本提供 Windows x64 便携版“智能任务管家-1.0.7.exe”，无需安装。程序未使用数字签名，Windows SmartScreen 或安全软件可能显示“未知发布者”；请从项目官方 GitHub Release 下载并核对发布页 SHA256。
