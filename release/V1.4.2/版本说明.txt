SmartTodo V1.4.2 版本说明
本地构建日期：2026-10-13（GitHub Release 尚未发布）

一、主要修复
1. 修复 Windows 已启用开机自启动时，设置页开关可能错误显示为关闭的问题。
2. 修复点击开启后系统写入成功，但开关因 Electron 启动项参数回读缺失而立即弹回的问题。
3. 保留带 --hidden 的完整启动登记；Windows 启用批准状态按持久外层 EXE 路径核对。

二、升级与数据兼容
- 升级前请从系统托盘完全退出旧版本。
- 保留既有任务、草稿、主题、会话、AI 配置、附件结构和 localStorage 键名。
- 自定义运行数据目录继续生效；本次升级不迁移或修改现有任务数据。
- 建议升级前备份整个运行数据目录，请勿分享其中的 API Key。

三、运行环境
- Windows x64 便携版，无需安装。
- 本构建未进行商业代码签名，首次运行可能出现 Windows SmartScreen 提示。

四、验证
- Node 自动化测试共 307 项：305 项通过、0 项失败、2 项因当前 Windows 环境无法创建测试用文件符号链接而跳过。
- 回归测试覆盖启动项已启用、但 Electron 31 将 launchItems[].args 返回为空数组的真实情况。
- 回归测试覆盖缺失自定义运行目录停止启动、应用目录双向迁移边界及迁移后可见重启。
- Electron 主界面、设置响应式矩阵与真实双窗口任务笺 UI 测试均通过。
- Windows x64 便携版构建成功；文件版本、产品版本和包内关键模块已核对。
