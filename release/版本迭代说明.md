# SmartTodo 版本迭代说明

本文汇总 SmartTodo 从附件可靠性修复、界面重构，到桌面任务笺、周期任务、品牌统一、设置中心及提醒交互的演进。历史发布目录中的 `版本说明.txt` 保留当时发布包的校验值与升级提示。

## 迭代总览

```text
V1.0.7 附件可靠性
   ↓
V1.2.0 现代新中式界面 + 桌面任务笺 + 响应式布局
   ↓
V1.2.1 布局、助手与任务笺交互修复
   ↓
V1.2.2 时间输入稳定性 + 亮度交互 + 操作反馈
   ↓
V1.3.0 周期任务 + 04:00 刷新 + 未完成承接
   ↓
V1.3.1 SmartTodo 品牌、包名与运行目录统一
   ↓
V1.4.0 统一设置 + Windows 隐藏自启动 + 完整运行目录迁移（源码审阅）
   ↓
V1.4.1 V1.4 正式发布 + 点击提醒唤起主窗口
```

## V1.4.1 · 提醒点击唤起与正式发布

发布日期：2026-10-13

- 点击 Windows 系统任务提醒时，自动恢复最小化或隐藏的 SmartTodo 主窗口，并将其聚焦到前台。
- 保留原有提醒声音、应用内提示、提醒指纹与周期去重逻辑；点击提醒不会自动完成或修改任务。
- V1.4 设置中心、开机自启动、完整运行数据迁移及其主进程模块均纳入便携版打包清单。
- 版本号、主窗口、任务笺、README、变更记录和发布说明统一更新为 V1.4.1。

发布文件与 SHA-256 见 [V1.4.1 版本说明](V1.4.1/版本说明.txt)。

## V1.4.0 · 设置与运行数据管理（打包前源码审阅）

源码审阅日期：2026-10-13；发布日期待批准及打包后确认。

- 全局齿轮打开常规，知行助手设置打开 AI；两者属于同一个常规／AI／存储设置中心，各模块单独操作。
- Windows 自启动以 `--hidden` 隐藏主窗口并驻留托盘，反映系统实际启用状态；手动启动显示主窗口，任务笺遵循既有偏好。
- AI 延续 DeepSeek、OpenAI 和自定义 OpenAI-compatible 地址／模型／Key，保留既有 localStorage 键；Key 默认遮蔽，关闭重遮蔽，本地保存不等于加密或联网验证。
- 存储页显示实际默认／自定义目录。迁移完整 Chromium 运行配置、任务／会话／AI／界面设置、附件及任务笺偏好，不移动 EXE。引导文件固定在 `%APPDATA%\SmartTodo\bootstrap.json`。
- 系统原生选择器发放短时一次性凭证；拒绝非空目标、源目标相同／包含、根目录／用户主目录、包围应用或引导配置的路径及链接目录，并校验权限。
- 刷新存储并记录请求后重启；在 Chromium 打开数据前复制到临时位置，核对相对路径／大小／SHA-256 清单，记录恢复日志并保留原目录的时间戳备份，再原子激活新目录。
- 复制／校验／备份失败不激活目标；中断可恢复到清单一致的源或备份，必须先保存恢复状态。无法确认原数据或保存恢复路径时停止启动；未激活副本可能保留。备份不自动清理。
- `runtime-data-manager.js`、`login-startup.js`、`app-settings-ipc.js` 和 `renderer/settings-controller.js` 分别管理目录事务、OS 启动状态、固定 IPC 能力及三模块交互。

验证依据：Node 用例覆盖文件事务、恢复、设置 IPC、OS 读回与控制器；两项既有文件符号链接用例受当前主机能力限制跳过。Task 6 的真实 Electron 设置矩阵为 11 组尺寸／缩放 × 双主题共 22 组，覆盖 480／639／640px 窄窗、125%／150% 缩放、长路径、滚动与可达操作、固定标题、零横向溢出，以及键盘／ARIA／焦点／Esc／Key 遮蔽。原工作台 8 组及任务笺三档缩放通过。跨进程恢复使用生产代码与临时文件，Electron／OS 边界为替身；未修改真实启动项或迁移用户数据。既有开发 CSP 警告和任务笺 fixture IPC 缺项仍有记录，不属于无警告二进制验收。

用户审阅通过后，才可打包或执行 GitHub 操作。EXE 文件名、大小、SHA-256、签名、GitHub URL、推送和 Release 发布均待用户批准及打包后确认，详见 [V1.4.0 源码审阅说明](V1.4.0/版本说明.txt)。本次没有打包或 GitHub 操作，不包含云同步、Key 联网验证、备份清理或 EXE 迁移。

## V1.3.1 · 品牌与运行环境统一

发布日期：2026-09-22

- npm 包、Windows 产品名、应用标识、窗口标题、托盘和文档统一使用 `SmartTodo`。
- Windows x64 便携包统一命名为 `SmartTodo-1.3.1.exe`。
- 当前运行数据目录统一为 `%APPDATA%\SmartTodo\运行数据`。
- 首次启动优先迁移 `%APPDATA%\智能任务管家\运行数据`，若不存在则兼容更早的 `%APPDATA%\smart-assistant`。
- SmartTodo 新目录已有数据时不会覆盖，既有任务、附件、会话、草稿、主题与 AI 设置保持兼容。
- 保留 V1.3.0 周期任务、现代新中式界面、桌面任务笺和此前全部交互修复。

验证结果：153 项单元测试中 151 项通过，2 项因当前 Windows 环境不支持创建符号链接而明确跳过，0 项失败；真实 Electron 主窗口、响应式矩阵和任务笺缩放测试通过。

便携包 SHA-256：`FDBA6BDEFA2C6E2554FA9008DF15616F99C3DD4F6451C4FB678AE6339467EB43`

## V1.3.0 · 周期任务

发布日期：2026-09-22

- 一次性任务仍为默认；主任务可选择每天、每周、每月或每年重复。
- 重复任务必须设置首次提醒时间，后续提醒按首次提醒的本地日期与时分投影。
- 新增本地周期边界：每天 04:00、每周一 04:00、每月 1 日 04:00、每年 1 月 1 日 04:00。
- 程序启动、窗口恢复可见以及跨日运行时都会执行幂等补刷新。
- 月末日期会夹取到当月最后一天；2 月 29 日在平年夹取，并在后续闰年恢复。
- 上一周期未完成时，新周期会增加一次性承接子任务；离线错过多期时合并显示期数，避免列表膨胀。
- 主界面和桌面任务笺均显示重复规则与承接状态，优先级、置顶和附件机制保持不变。
- 提醒指纹本地持久化，当前周期到期提醒在程序重启后不会重复发送。
- 修复亮度值 `100%` 换行错位，并保证承接子任务仍可访问原周期附件。

## V1.2.2 · 输入稳定性与交互反馈

发布日期：2026-09-22

- 修复双击提醒时间“分钟”分段时，部分 Windows 显卡环境下整个窗口可能黑屏的问题。
- 生产程序改用稳定的软件合成，并阻止原生时间分段的异常二次重绘路径。
- 修复亮度按钮与浮层之间的悬停断层，鼠标可直接从图标移动到拉条。
- 亮度浮层增加 180ms 离开容错，继续支持点击聚焦、键盘操作、Esc 收起和双击恢复 100%。
- 为按钮、筛选、任务复选框和输入控件增加克制且清晰的按压、聚焦和选中反馈。
- 任务筛选增加同步的 `aria-pressed` 状态，使鼠标、键盘和辅助技术获得一致反馈。

## V1.2.0 · 界面重构与桌面任务笺

发布日期：2026-09-21

- 品牌名称更新为 SmartTodo，重新绘制竹叶流萤应用图标、托盘图标和界面线性图标。
- 主界面升级为“文房案台／漆夜流萤”现代新中式深浅双主题。
- 重构任务工作台、知行助手、筛选、附件、对话框、状态反馈和长内容布局。
- 新增 320×440 桌面任务笺，最多展示 5 项未完成任务，支持完成、打开主界面与收起。
- 新增任务笺托盘开关、主界面入口、位置／可见性记忆和显示器变化后的安全回收。
- 任务笺不置顶、不抢焦点，并采用脱敏快照、固定 IPC、发送者校验、请求超时和保存失败回滚。
- 覆盖 1366×768 至 2560×1440、窄窗口以及 Windows 125%／150% 缩放。
- 增加本地 GSAP 状态动效和完整的 `prefers-reduced-motion` 回退。
- 继续兼容 V1.0.7 的任务、会话、草稿、AI 配置、`localStorage` 键名和附件结构。

## V1.0.7 · 附件显示与清理可靠性

发布日期：2026-09-15

- 修复已保存附件错误显示“文件已不存在”的样式优先级问题。
- 只有主进程确认附件缺失、不安全或无法解析时才显示缺失提示。
- 增加真实窗口回归测试，防止正常附件状态再次被错误覆盖。
- 已完成任务的附件不会立即删除，以保留 15 天内撤销能力。
- 已完成超过 15 天的任务自动清理时，会同步清理主任务、子任务及对应附件目录。
- 手动删除任务时同步删除附件目录；程序启动时幂等清理没有任务引用的孤立附件。
- 不改变任务、备注或附件数据结构，兼容 V1.0.6 运行数据。

## 升级原则

- 升级前先从系统托盘完全退出旧版本，避免同时运行两个版本。
- 建议备份整个“运行数据”目录，尤其是在跨版本迁移前。
- V1.3.1 引入的默认目录兼容迁移继续保留；默认目录已有 Chromium Local Storage 时不覆盖，自定义目录不迁移到未使用的默认目录。
- 请勿分享运行数据目录，其中可能包含任务附件、会话内容和 API Key。
- 便携包未进行商业代码签名，Windows SmartScreen 可能显示“未知发布者”；下载时请核对对应发布页校验值。
