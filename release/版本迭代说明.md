# SmartTodo 版本迭代说明

本文汇总 SmartTodo 从附件可靠性修复、界面重构，到桌面任务笺、周期任务和品牌统一的完整演进。各发布目录中的 `版本说明.txt` 继续保留，用于记录当时发布包的校验值和升级提示；本文作为面向使用者的统一版本时间线。

## 迭代总览

```text
V1.0.7 附件可靠性
   ↓
V1.2.0 现代新中式界面 + 桌面任务笺 + 响应式布局
   ↓
V1.2.1 布局、助手与任务笺交互修复
   ↓
V1.2.2 时间输入稳定性 + 亮度交互 + 操作反馈
   ↓
V1.3.0 周期任务 + 04:00 刷新 + 未完成承接
   ↓
V1.3.1 SmartTodo 品牌、包名与运行目录统一
```

## V1.3.1 · 品牌与运行环境统一

发布日期：2026-09-22

- npm 包、Windows 产品名、应用标识、窗口标题、托盘和文档统一使用 `SmartTodo`。
- Windows x64 便携包统一命名为 `SmartTodo-1.3.1.exe`。
- 当前运行数据目录统一为 `%APPDATA%\SmartTodo\运行数据`。
- 首次启动优先迁移 `%APPDATA%\智能任务管家\运行数据`，若不存在则兼容更早的 `%APPDATA%\smart-assistant`。
- SmartTodo 新目录已有数据时不会覆盖，既有任务、附件、会话、草稿、主题与 AI 设置保持兼容。
- 保留 V1.3.0 周期任务、现代新中式界面、桌面任务笺和此前全部交互修复。

验证结果：153 项单元测试中 151 项通过，2 项因当前 Windows 环境不支持创建符号链接而明确跳过，0 项失败；真实 Electron 主窗口、响应式矩阵和任务笺缩放测试通过。

便携包 SHA-256：`FDBA6BDEFA2C6E2554FA9008DF15616F99C3DD4F6451C4FB678AE6339467EB43`

## V1.3.0 · 周期任务

发布日期：2026-09-22

- 一次性任务仍为默认；主任务可选择每天、每周、每月或每年重复。
- 重复任务必须设置首次提醒时间，后续提醒按首次提醒的本地日期与时分投影。
- 新增本地周期边界：每天 04:00、每周一 04:00、每月 1 日 04:00、每年 1 月 1 日 04:00。
- 程序启动、窗口恢复可见以及跨日运行时都会执行幂等补刷新。
- 月末日期会夹取到当月最后一天；2 月 29 日在平年夹取，并在后续闰年恢复。
- 上一周期未完成时，新周期会增加一次性承接子任务；离线错过多期时合并显示期数，避免列表膨胀。
- 主界面和桌面任务笺均显示重复规则与承接状态，优先级、置顶和附件机制保持不变。
- 提醒指纹本地持久化，当前周期到期提醒在程序重启后不会重复发送。
- 修复亮度值 `100%` 换行错位，并保证承接子任务仍可访问原周期附件。

## V1.2.2 · 输入稳定性与交互反馈

发布日期：2026-09-22

- 修复双击提醒时间“分钟”分段时，部分 Windows 显卡环境下整个窗口可能黑屏的问题。
- 生产程序改用稳定的软件合成，并阻止原生时间分段的异常二次重绘路径。
- 修复亮度按钮与浮层之间的悬停断层，鼠标可直接从图标移动到拉条。
- 亮度浮层增加 180ms 离开容错，继续支持点击聚焦、键盘操作、Esc 收起和双击恢复 100%。
- 为按钮、筛选、任务复选框和输入控件增加克制且清晰的按压、聚焦和选中反馈。
- 任务筛选增加同步的 `aria-pressed` 状态，使鼠标、键盘和辅助技术获得一致反馈。

## V1.2.1 · 布局与任务笺修复

发布日期：2026-09-21

- 修复任务行“子任务”、折叠、优先级等操作控件在部分尺寸下交叉错位的问题。
- 修复主界面任务笺按钮只能显示、无法再次点击收起的问题，并在启动时同步真实可见状态。
- 修复知行助手连续消息和头像因负边距、强制位移导致的交叉现象。
- 修复顶部工具区基线错位。
- 桌面任务笺移除重复的主界面入口，并增强半透明毛玻璃质感。
- 发布文件使用独立的 V1.2.1 文件名和目录，避免与旧包混淆。

## V1.2.0 · 界面重构与桌面任务笺

发布日期：2026-09-21

- 品牌名称更新为 SmartTodo，重新绘制竹叶流萤应用图标、托盘图标和界面线性图标。
- 主界面升级为“文房案台／漆夜流萤”现代新中式深浅双主题。
- 重构任务工作台、知行助手、筛选、附件、对话框、状态反馈和长内容布局。
- 新增 320×440 桌面任务笺，最多展示 5 项未完成任务，支持完成、打开主界面与收起。
- 新增任务笺托盘开关、主界面入口、位置／可见性记忆和显示器变化后的安全回收。
- 任务笺不置顶、不抢焦点，并采用脱敏快照、固定 IPC、发送者校验、请求超时和保存失败回滚。
- 覆盖 1366×768 至 2560×1440、窄窗口以及 Windows 125%／150% 缩放。
- 增加本地 GSAP 状态动效和完整的 `prefers-reduced-motion` 回退。
- 继续兼容 V1.0.7 的任务、会话、草稿、AI 配置、`localStorage` 键名和附件结构。

## V1.0.7 · 附件显示与清理可靠性

发布日期：2026-09-15

- 修复已保存附件错误显示“文件已不存在”的样式优先级问题。
- 只有主进程确认附件缺失、不安全或无法解析时才显示缺失提示。
- 增加真实窗口回归测试，防止正常附件状态再次被错误覆盖。
- 已完成任务的附件不会立即删除，以保留 15 天内撤销能力。
- 已完成超过 15 天的任务自动清理时，会同步清理主任务、子任务及对应附件目录。
- 手动删除任务时同步删除附件目录；程序启动时幂等清理没有任务引用的孤立附件。
- 不改变任务、备注或附件数据结构，兼容 V1.0.6 运行数据。

## 升级原则

- 升级前先从系统托盘完全退出旧版本，避免同时运行两个版本。
- 建议备份整个“运行数据”目录，尤其是在跨版本迁移前。
- V1.3.1 会自动迁移历史目录，但 SmartTodo 新目录已有数据时不会覆盖。
- 请勿分享运行数据目录，其中可能包含任务附件、会话内容和 API Key。
- 便携包未进行商业代码签名，Windows SmartScreen 可能显示“未知发布者”；请从项目官方 GitHub Releases 下载并核对发布页校验值。
