SmartTodo V1.3.1 版本说明
发布日期：2026-09-22

一、主要更新
1. npm 包、Windows 产品名、应用标识、窗口、托盘和文档统一使用 SmartTodo。
2. Windows x64 便携包统一命名为 SmartTodo-1.3.1.exe。
3. 当前运行数据目录统一为 %APPDATA%\SmartTodo\运行数据。
4. 保留 V1.3.0 的周期任务、桌面任务笺、现代新中式界面与全部交互修复。

二、升级与数据兼容
- 升级前请从系统托盘完全退出旧版本。
- 首次启动优先迁移 %APPDATA%\智能任务管家\运行数据。
- 若上一目录不存在，则兼容迁移更早的 %APPDATA%\smart-assistant。
- SmartTodo 新目录已有数据时不会覆盖；既有任务、附件、会话和设置保持兼容。
- 建议升级前备份旧“运行数据”目录；不要分发其中的 API Key。

三、运行环境
- Windows x64 便携版，无需安装。
- 本构建未进行商业代码签名，首次运行可能出现 Windows SmartScreen 提示。

四、验证
- 153 项单元测试：151 项通过，2 项因当前 Windows 环境不支持符号链接而跳过，0 项失败。
- 真实 Electron 主窗口、8 组响应式尺寸／缩放和任务笺三档缩放测试通过。
