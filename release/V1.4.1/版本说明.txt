SmartTodo V1.4.1 版本说明
发布日期：2026-10-13

一、主要更新
1. 点击系统任务提醒时，SmartTodo 会恢复最小化或隐藏的主窗口，并将窗口聚焦到前台。
2. 正式发布统一设置中心、Windows 隐藏自启动和完整运行数据目录迁移。
3. 保留原有提醒声音、应用内提示、提醒去重与周期任务行为；点击提醒不会修改任务状态。

二、升级与数据兼容
- 升级前请从系统托盘完全退出旧版本。
- 保留既有任务、草稿、主题、会话、AI 配置、附件结构和 localStorage 键名。
- 自定义运行数据目录继续生效；迁移产生的时间戳备份不会自动删除。
- 建议升级前备份整个运行数据目录，请勿分享其中的 API Key。

三、运行环境
- Windows x64 便携版，无需安装。
- 本构建未进行商业代码签名，首次运行可能出现 Windows SmartScreen 提示。

四、验证
- Node 自动化测试共 303 项：301 项通过、0 项失败、2 项因当前 Windows 环境无法创建测试用文件符号链接而跳过。
- Electron 主界面／响应式／任务笺 UI 测试均通过。
- 回归测试覆盖点击系统任务提醒后恢复、显示并聚焦主窗口。
- 便携版已验证包含 V1.4 新增的启动、运行目录与设置 IPC 模块。
